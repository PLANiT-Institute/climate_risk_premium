# Climate Risk Premium (CRP) Model — Overview

**Subject:** Samcheok Blue Power Plant (삼척블루파워, 2,100 MW supercritical coal, South Korea)
**Purpose:** Quantify the climate risk premium embedded in project finance cost of capital under transition and physical risk scenarios.

---

## 1. What the Model Does

The model computes the **Climate Risk Premium (CRP)** in basis points — the additional spread above a no-risk counterfactual that lenders and equity investors should demand given climate risks. It does this by:

1. Projecting year-by-year cash flows under 11 risk scenarios
2. Computing financial KPIs (NPV, IRR, DSCR, LLCR)
3. Mapping financial health to a KIS-style credit rating (AAA → D)
4. Converting the rating migration to a CRP in basis points via counterfactual comparison

## 4. Module Descriptions

### `src/data/data_loader.py`
Loads all CSV inputs and returns typed dataclasses. Bottom layer — no dependencies on other `src/` modules.

| Class | Key fields |
|-------|-----------|
| `PlantParameters` | capacity_mw=2100, total_capex_million=3550, debt_fraction=0.80, debt_tenor_years=30, depreciation_years=30, amortization_type, target_dscr |
| `DataLoader` | `load_all()` → `{plant, transition, physical, market, financing, transmission, credit_grid}` |

---

### `src/scenarios/`
Defines scenario types. No dependencies on other `src/` modules.

| Class | Purpose |
|-------|---------|
| `TransitionScenario` | `dispatch_priority_penalty`, `retirement_years` |
| `MarketScenario` | `get_demand_factor(year)`, `get_power_price(year)` |
| `KoreaPowerPlanScenario` | Year-by-year dispatch from Korea's 10th Basic Plan CSV |
| `EnhancedKoreaPowerPlanScenario` | 11th Basic Plan + carbon pricing pathways |

---

### `src/risk/physical.py`
Converts PLANiT hazard outputs into six impact channels applied in the cash flow engine.

| Channel | Effect | Hazard driver |
|---------|--------|---------------|
| `outage_rate` | Reduces available generation hours | Wildfire, typhoon |
| `capacity_derate` | Reduces cooling capacity → lower max CF | Drought |
| `efficiency_loss` | Raises effective heat rate → higher fuel cost | Heat stress, drought |
| `water_constrained_capacity` | Hard cap on CF under extreme drought | Water stress |
| `transmission_outage_rate` | Grid-side unavailability | Wildfire/flood on lines |
| `asset_capex_loss_rate` | Annual fraction of plant value destroyed | All acute hazards |

`YearlyPhysicalAdjustments` provides year-by-year arrays for dynamic climate change progression (via SSP scenario × year interpolation from `climate_factors.csv`).

**Outage model:**
```
annual_outage_rate = event_frequency × P(outage | event) × outage_duration / 8760
P(outage | event) = 1 − exp(−λ × t)   [from outage_params.csv]
```

**Combined plant + transmission outage (independent failure modes):**
```
total_outage = 1 − (1 − plant_outage) × (1 − line_outage)
```

---

### `src/risk/transition.py`
Applies policy-driven dispatch penalties and early retirement to the capacity factor.

```
adjusted_CF = baseline_CF × (1 − dispatch_penalty)
```

Priority order: `EnhancedKoreaPowerPlan` > `KoreaPowerPlan` > `TransitionScenario.dispatch_penalty`

---

### `src/risk/credit_rating.py`
Maps financial metrics to a KIS-style rating via weighted average, then applies a DSCR override.

**Weighted score (weights sum to 1.0):**

| Component | Weight | Metric |
|-----------|--------|--------|
| `policy_industry` | 0.50 | Fixed AA for coal sector |
| `profitability` | 0.10 | EBITDA / total assets |
| `coverage` | 0.12 | EBITDA / interest expense |
| `net_debt_leverage` | 0.12 | Net debt / EBITDA |
| `asset_leverage` | 0.08 | Total debt / total assets |
| `equity_leverage` | 0.08 | Total debt / total equity |

**DSCR override (applied after weighted score, not part of the weighted average):**
- `DSCR < 0` → force D
- `DSCR < 1.0` → +1 notch downgrade

**Rating scale:** AAA(1) → AA(2) → A(3) → BBB(4) → BB(5) → B(6) → CCC(7) → CC(8) → C(9) → D(10)

**Spread mapping** (from `rating_spreads.csv`):

| Rating | Spread (bps) |
|--------|-------------|
| AAA | 50 |
| AA | 100 |
| A | 150 |
| BBB | 250 |
| BB | 400 |
| B | 600 |
| CCC | 900 |
| CC | 1,500 |
| C | 2,500 |
| D | 5,000 |

---

### `src/risk/financing.py`
Translates rating migration into CRP basis points.

```
CRP (bps) = Scenario Spread (bps) − Counterfactual Spread (bps)
```

Where counterfactual = no-risk baseline rating spread (typically A = 150 bps).

---

### `src/risk/attribution.py`
Shapley-value decomposition of CRP into transition and physical components.

```
Interaction = Combined − Transition-only − Physical-only + Baseline
Transition share = (Transition-only − Baseline) + 0.5 × Interaction
Physical share   = (Physical-only − Baseline)   + 0.5 × Interaction
```

---

### `src/financials/cashflow.py`
Year-by-year cash flow projection over the plant's operating life.

**Revenue:**
```
actual_MWh = capacity_MW × 8760 × CF × water_cap × (1 − outage_rate)
revenue    = actual_MWh × power_price
```

**Costs:**
```
fuel_cost     = actual_MWh × heat_rate × (1 + efficiency_loss) × fuel_price
variable_opex = actual_MWh × variable_opex_per_MWh
fixed_opex    = capacity_MW × 1000 × fixed_opex_per_kW   [constant]
```

**Key modeling choices:**
- Outages **reduce revenue** (lost sales), not add costs
- Efficiency loss increases effective heat rate → higher fuel cost
- `lost_revenue_from_outages` is tracked separately for transparency but not included in total costs

**Debt service (annuity mode):**
```
annual_DS = PMT(rate, tenor, debt_amount)   [numpy_financial.pmt]
DSCR      = CFADS / annual_DS
CFADS     = EBITDA − tax − maintenance_capex
```

---

### `src/financials/metrics.py`
Computes project finance KPIs from `CashFlowTimeSeries`.

| Metric | Formula |
|--------|---------|
| NPV | Σ FCF_t / (1+r)^t |
| IRR | r where NPV = 0 |
| Avg DSCR | Mean(CFADS_t / DS) over debt period |
| Min DSCR | Min(DSCR_t) over debt period |
| LLCR | PV(CFADS over remaining loan life) / outstanding debt |

---

### `src/planit/`
Interfaces with the PLANiT hazard model (CLIMADA + PhysRisk).

- **`PLANiTRunner`**: Calls PLANiT `main.py` (if live) or loads pre-computed CSVs (default `CRP_PLANIT_MODE=csv`)
- **`PLANiTAdapter`**: Converts `PLANiTHazardResult` → `PhysicalAdjustments` via hazard baseline + climate factor interpolation
- **`PLANiTIntegrationConfig`**: Active hazards = {wildfire, drought, water_risk}

**SSP scenario mapping:**

| CRP Scenario | PLANiT SSP | Year |
|-------------|-----------|------|
| baseline | ssp126 | 2024 |
| moderate_physical | ssp245 | 2040 |
| high_physical | ssp585 | 2040 |
| severe_drought | ssp585 | 2050 |

---

### `src/pipeline/runner.py` — CRPModelRunner
Main orchestrator. Coordinates all modules for a single scenario run.

**`run_scenario()` execution order:**
1. Load transition scenario → `TransitionScenario`
2. Load physical scenario via PLANiT adapter → `PhysicalAdjustments`
3. Apply transition penalties → `TransitionAdjustments`
4. Optionally build year-by-year physical evolution → `YearlyPhysicalAdjustments`
5. Compute cash flows → `CashFlowTimeSeries`
6. Calculate financial metrics → `FinancialMetrics`
7. Assess credit rating → `RatingAssessment`
8. Compute counterfactual CRP → `crp_bps`
9. Compute financing impact → `FinancingImpact`
10. Assemble `ScenarioResult`

| `high_physical` | none | ssp585/2040 | base |
| `combined_moderate` | moderate | ssp245/2040 | base |

## 9. How to Run

**Reproduce canonical results:**
```bash
python scripts/reproduce_results.py
```

**Rebuild dashboard data (including yearly_ratings.csv):**
```bash
python scripts/regenerate_dashboard_data.py
```

**Interactive Streamlit dashboard:**
```bash
streamlit run app.py
```

**Minimal Python API:**
```python
from pathlib import Path
from src.pipeline.runner import CRPModelRunner

runner = CRPModelRunner(Path("."))
results = runner.run_multi_scenario()

for name, r in results.items():
    print(f"{name:35s} | NPV: {r.metrics.npv/1e6:+8.1f}M | "
          f"Rating: {r.credit_rating.overall_rating.name:4s} | "
          f"CRP: {r.counterfactual_crp.get('crp_bps', 0):.0f} bps")
```
